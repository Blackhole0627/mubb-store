# MUBB Store

E-commerce for MUBB (mubb.store/tienda), added on top of the existing WordPress site without touching it. Same design language as the live site, restyled for a full store: catalog, cart, checkout, and Datafast/Kushki payments.

## Contents
- `STEP1-design-and-architecture.md` — scope, sitemap, data model, and payment architecture
- `wireframes/index.html` — low-fidelity wireframes (open in a browser)
- `tokens.css` — design tokens copied from the live site
- `shared/store-schema.sql` — the e-commerce data model (shared with the SACRUM store)
- `reference-clone/` — a local clone of the live mubb.store pages, styles, fonts, and images, used as the design reference

Step 1 (design and architecture) is complete. Step 2 is implementation.
